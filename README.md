# Scratch 1.x

An archival and research project focused on the **Scratch 1.x series**.

This project is being prepared to document and preserve information about the early Scratch 1.x versions, including their interfaces, programming blocks, projects, assets, and history.

## About Scratch 1.x

Scratch 1.x was the first major version series of the Scratch programming environment.

Scratch allowed users to create:

- Interactive stories
- Games
- Animations
- Music projects
- Simulations
- Art
- Educational projects

Instead of typing traditional programming code, users could connect graphical programming blocks together to create scripts.

## Versions

This repository covers the Scratch 1.x series:

- Scratch 1.0
- Scratch 1.1
- Scratch 1.2
- Scratch 1.3
- Scratch 1.4

## Historical Accuracy

Information should be associated with the specific Scratch version it describes.

A feature from Scratch 1.4 should not automatically be assumed to have existed in Scratch 1.0.

When possible, version-specific information should be checked against historical documentation, archived software, screenshots, and other reliable sources.

## Preservation

This project is intended to help preserve information about the early Scratch 1.x era.

Original files should be kept unchanged when they are being archived. Recreated or modified files should be clearly identified as recreations or modifications.
